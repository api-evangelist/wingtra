## API surfaces

- [Wingtra Customer and Partner Portal GraphQL API](https://api.my.wingtra.com/graphql): the back end of my.wingtra.com. 84 types, 38 query fields, 33 mutations covering drone registration and setup, warranty and paid replacement eligibility, PPK/LiDAR/Blue sUAS licence configuration and transfer, payload registration, WingtraCARE plan changes, reseller tenancy, and SSO token exchange to WingtraCLOUD, HubSpot, Thinkific and Canny. Undocumented and unversioned. Anonymous schema introspection is open; every field resolver requires a bearer token Wingtra does not issue to third parties.
- [WingtraCLOUD API](https://api.sky.wingtra.com): the versioned REST API the WingtraCLOUD browser client calls — sites, flights, drones, layers, jobs, tenants, file registration and presigned upload, and a coordinate systems and transformation service under /v1. No published specification. Every unauthenticated request returns HTTP 400 "Something went wrong."

## Certifications

Blue UAS Cleared List (US DIU), NDAA Section 848 compliant hardware, DIU Authority to Operate, Green UAS (AUVSI), FAA Category 3 operations over people, and C6 class certification for WingtraRAY in Europe. These certify the aircraft, not the API or the cloud service; Wingtra publishes no SOC 2, ISO 27001 or trust center.

## Integration reality

Wingtra integrates with the geospatial toolchain by file exchange, not by API: Trimble Business Center, ArcGIS Online, Propeller, Pix4D, Bentley iTwin and DroneDeploy, plus 6,500+ EPSG coordinate systems, RINEX and Trimble .T02/.T04 input, and LAS/LAZ, GeoTIFF and KML output. An agent that wants Wingtra data works with those files.
